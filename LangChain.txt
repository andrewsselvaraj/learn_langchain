Beginner Level
1. What is LangChain?
LangChain is an open-source framework used to build applications powered by Large Language Models (LLMs). It provides components like prompts, chains, memory, retrievers, agents, and tools.
2. Why do we need LangChain?
Connect LLMs with external systems
Access databases and APIs
Maintain conversation history
Build multi-step workflows
Create AI agents
3. What is a Chain in LangChain?
A chain combines multiple components into a workflow.
Example:
User Query
   ↓
Prompt
   ↓
LLM
   ↓
Output
4. What is PromptTemplate?
Used to create reusable prompts with variables.
Example:
Java
"Explain {topic} in simple terms"
5. What is an LLM?
A Large Language Model that generates text from prompts.
Examples:
GPT-4
Claude
Gemini
Llama
Azure OpenAI
Intermediate Level
6. What is Memory in LangChain?
Memory stores conversation history and context.
7. Types of Memory
ConversationBufferMemory
ConversationSummaryMemory
VectorStoreMemory
8. What is Retrieval Augmented Generation (RAG)?
RAG retrieves information from external data before sending context to the LLM.
9. Advantages of RAG?
Reduces hallucination
Uses latest enterprise data
No retraining required
Cost effective
10. What is Embedding?
A numerical vector representation of text.
Example:
"Java" → [0.12,0.34,0.95....]
11. What is Chunking?
Breaking large documents into smaller pieces before generating embeddings.
12. What is a Vector Database?
A database optimized for storing and searching embeddings.
Examples:
Pinecone
ChromaDB
Milvus
Weaviate
Azure AI Search
13. What is Similarity Search?
Finding the closest vectors using:
Cosine Similarity
Dot Product
Euclidean Distance
14. What is a Retriever?
A component that finds relevant documents from a vector store.
15. Difference Between Retriever and Vector Store?
Vector Store
Stores embeddings
Retriever
Searches embeddings
Advanced Level
16. What is an Agent?
An AI component that decides which action/tool to execute.
17. Agent vs Chain
Chain
Fixed workflow
Predictable execution
Agent
Dynamic workflow
Chooses tools automatically
18. What are Tools?
External functions or APIs used by agents.
Examples:
Calculator
Weather API
Database Query
Search Engine
19. What is Function Calling?
LLM selects and invokes application functions.
20. What is Tool Calling?
Enhanced function calling where multiple tools can be called automatically.
21. What is ReAct Agent?
Reason + Act pattern.
Flow:
Think
↓
Select Tool
↓
Execute
↓
Observe
↓
Answer
